# Novel09 天元界世界地图与势力视觉

> 本文件用于世界地图、势力图标、地图配色和大型场景远景设计。
>
> 现有 Bible 已固定世界由边域、诸域、中央大域与域外构成。本文件只做视觉与空间表达，不额外扩大世界层级。

---

# 一、天元界总地图的核心思路

不要把天元界画成一块普通完整大陆。

推荐视觉：

**中央大域位于文明核心，外围由多片古州、大陆、海域和断裂地形构成；越靠边缘，地形越破碎，最终过渡到无法正常制图的域外边界。**

它应该像一张经历过漫长历史、战争和地质变化的巨大修真世界地图。

---

# 二、四级空间的地图表达

## 1. 中央大域

位置：地图中心偏北或中心。

视觉特征：

- 最大的连续文明地带；
- 山脉、河流、古城、传送节点最密集；
- 大型势力之间距离依然很远；
- 不要把天衍圣宗、楚氏、大衍神朝画成隔壁三个院子。

推荐地貌：

- 西北高山宗门带；
- 中央古州平原与河网；
- 东部大湖/内海；
- 南部皇朝腹地；
- 若干远古禁区嵌入山脉和荒原。

## 2. 诸域

围绕中央大域分布，但不是一整圈规则环带。

可以由：

- 北境寒原诸州；
- 东海群域；
- 西荒高原；
- 南岭与古林诸域；
- 若干独立大州。

组成。

这些名字可先只作为地图视觉分区，不强行成为正文正式地名。

## 3. 边域

陆沉舟前期成长地。

视觉上应明显远离中央文明核心。

推荐放在地图 **东南或西南远端** 的一片较封闭地带：

- 大山隔绝；
- 传送节点少；
- 宗门规模小；
- 有多个凡俗国家；
- 地图上的城市和修行据点密度明显下降。

这样后续陆沉舟一路进入诸域、中央大域，视觉上真的有“走向世界中心”的感觉。

## 4. 域外

域外不能画成地图边缘一块普通黑色国家。

正确表达：

- 天元界边缘之外存在破碎空间；
- 大陆边缘、古海尽头、极北/极西等位置都有可能接触域外裂界；
- 地图边缘逐渐出现断裂、错位、缺失区域；
- 部分区域只能以符号标记，不能正常绘制地形。

视觉上让整张地图像“正常世界到边缘以后开始无法被完整画下来”。

# 三、中央大域势力位置建议

以下只用于第一版视觉排布。

## 天衍圣宗

建议位于中央大域 **西北部大型祖脉山系**。

原因：

- 山宗视觉合理；
- 与域外古裂界、古禁区历史联系更自然；
- 可通过古道和传送阵连接中央大域核心城市。

## 楚氏

建议位于中央大域 **东部或东南部富庶古州**。

视觉：

- 大河；
- 古城；
- 大片灵田与家族领地；
- 多条商路和传送网络。

这能强化楚氏影响宗门的方式不只是“高手多”，而是拥有资源、贸易和联盟网络。

## 宁氏

建议位于天衍圣宗与中央腹地之间的一片较小古州。

视觉：

- 有自己的城、山庄、灵脉；
- 规模和节点数量明显小于楚氏；
- 仍然属于真正有底蕴的世家。

## 大衍神朝

建议占据中央大域 **南部大片连续疆土**。

必须有国家尺度：

- 皇都；
- 多座大城；
- 河道；
- 边关；
- 官道/传送干线。

不要只画一座皇宫代表整个神朝。

## 古禁区 / 禁物来源区域

建议位于中央大域西北偏西、接近天衍圣宗但不属于宗门腹地的荒山裂谷带。

这样旧案中的禁物交易可以具有真实运输路线：

**古禁区 → 隐秘转运点 → 楚氏涉事支脉/中间商路 → 天衍圣宗内部旧派。**

地图后续可以单独画一张“旧案暗线交通图”。

# 四、地图视觉风格

## 推荐风格 A：写实古地图

- 高低起伏明显的山体；
- 河流和海岸真实；
- 城池与宗门用精细图标；
- 背景为浅灰米色纸感或淡青灰；
- 用少量势力色做区域边缘或图标，不整块高饱和涂色。

适合作为设定集正式地图。

## 推荐风格 B：电影世界鸟瞰图

- 不是平面纸地图；
- 像从高空俯视整个大陆；
- 能看到云层、山脉、大河和城市光点；
- 域外边缘出现空间破碎。

适合作为宣传图或卷首页。

## 推荐风格 C：势力关系战略图

- 地形降低细节；
- 强调势力范围、商路、古传送阵、冲突点；
- 用于理解政治关系。

# 五、各势力视觉识别

## 1. 天衍圣宗

主色：**银灰 + 青黑 + 冷白。**

图形元素：

- 山峰；
- 古剑；
- 天穹圆环/星轨；
- 但不要直接把宗门 Logo 做成月亮，因为月色更偏照月峰和沈照夜个人体系。

建筑：青灰石、深木、银灰瓦。

## 2. 照月峰

主色：**月白 + 冷银 + 极淡蓝。**

图形：半月、水面倒影、细长剑。

## 3. 玄岳峰

主色：**岩黑 + 土黄 + 暗金。**

图形：厚重山形、断岩、宽刃。

## 4. 楚氏

主色：**象牙白 + 温玉色 + 浅金。**

辅助色可用低饱和烟粉/灰紫。

图形：

- 玉璧；
- 回纹；
- 双层门阙；
- 不建议用凤凰这类过度常见豪门符号。

## 5. 宁氏

主色：**白石色 + 雾青 + 青玉。**

图形：

- 细竹；
- 水滴；
- 青玉叶；
- 简洁院门。

## 6. 大衍神朝

主色：**玄黑 + 深朱 + 暗金。**

图形：

- 城阙；
- 日轮或天衡；
- 宽阔轴线。

不使用纯金龙作为唯一视觉。

## 7. 沈照夜域外势力

名称尚未锁定前，只锁视觉。

主色：**石墨黑 + 失色灰 + 冷紫灰 + 极淡幽蓝。**

图形：

- 不闭合圆环；
- 断裂竖线；
- 黑晶；
- 被切开的星图；
- 不规则但高度克制。

不要使用骷髅、恶魔翅膀、血手印。

# 六、域外视觉设计

域外最重要的不是“黑”，而是**物理规则看起来有问题**。

可固定以下视觉现象：

1. 远山透视方向不一致；
2. 同一片地面出现两种不同重力方向的碎石；
3. 天空有巨大但极淡的断层；
4. 没有太阳却存在方向不明的冷光；
5. 黑晶像从地表内部长出；
6. 某些遗迹一半风化、一半像刚切开；
7. 影子不完全服从光源；
8. 雾不是漂浮，而像静止在空间中。

域外不要全程恐怖血腥。

它应该同时拥有“壮丽”和“不应该存在”。

# 七、天元界总地图 AI 提示词

东方玄幻超大世界地图，名为天元界，不是一整块规则大陆，由中央大域、外围诸域、遥远边域、海域、古州、禁区和破碎世界边缘共同构成，中央大域文明最密集，西北大型祖脉山系中坐落顶级天衍圣宗，东南富庶古州为楚氏势力区域，天衍圣宗与中央腹地之间有规模较小的宁氏世家领地，南方大片连续疆土属于大衍神朝，远端边域被大山和漫长距离隔离，世界边缘逐渐出现破碎空间、断裂大陆、错位地形与无法正常绘制的域外区域，巨大山脉、河流、内海、古城、传送节点、荒原、禁区分布合理，古典东方山水地图与电影级世界概念设计融合，宏大但真实，无现代UI，无西式奇幻地图符号，无文字乱码，16:9。

---

# 八、域外概念图 AI 提示词

东方玄幻世界之外的破碎域外空间，巨大断裂岩层悬浮在无明确天空与地面的灰暗空间中，远方山体透视方向互相矛盾，黑晶从岩层内部生长，古老遗迹一半严重风化一半切面异常光滑，极淡冷蓝和冷紫灰光从未知方向照亮环境，部分碎石悬停，空间像透明玻璃般出现巨大细裂，雾凝固在半空，壮丽、安静、危险、规则失效，不是地狱，不是血海，不是赛博朋克，电影级东方玄幻概念设计，超广角环境图。
