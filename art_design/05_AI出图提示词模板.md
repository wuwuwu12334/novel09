# 二、通用角色一致性模板

当已经有一张满意的角色图后，把参考图交给模型，并附加：

```text
严格保持参考图中的同一人物身份。
不要重新设计脸。
保持相同脸型、眉形、眼型、鼻唇比例、发际线、发型主体结构、身高比例和标志性饰物。
只改变本次要求中的姿势、表情、场景、镜头和允许变化的服装层次。
人物必须像同一个演员在不同场景中，而不是相似的新角色。
```

如果模型容易跑脸，再补：

```text
same character, same face identity, consistent facial geometry, consistent hairstyle silhouette, consistent body proportions, character sheet continuity
```

# 十四、战斗提示词结构

不要只写“大战、特效华丽”。

正确结构：

```text
1. 起势：环境先发生什么变化；
2. 显形：双方力量分别形成什么清晰形态；
3. 运动：招式从哪里向哪里移动；
4. 碰撞：两种力量在哪里正面冲突；
5. 人物：人物身体动作与受力方向；
6. 余波：山壁、擂台、树木、云海发生什么变化；
7. 镜头：远景交代尺度，中景保证人物可读。
```

### 示例：少年沈照夜战斗

```text
沈照夜在巨大山谷论道台上拔剑，剑未完全出鞘时冷白剑辉先从鞘口渗出，衣袍与黑色长发被无风掀起。数十道银白月弧剑影从不同高度展开，极淡蓝色边缘像月光铺过水面；对手的厚重山岳刀势从正面压来，暗金与岩黑色山岳虚影覆盖半个擂台。两股力量在半空正面碰撞，冷白月轮切入山岳刀罡，空气形成环形气浪，护场阵壁成片亮起，山壁留下巨大剑痕和崩裂岩层。人物动作连续，具有速度、方向和重量。16:9电影级东方玄幻战斗概念图，强视觉奇观但不过曝。
```

# 十七、最重要的执行原则

如果某个模型一次想同时重新设计：脸、服装、发型、武器、场景、特效，最容易失控。

正确做法是：

**先锁人 → 再锁衣服 → 再锁地点 → 最后画剧情。**

Novel09 后续所有高质量插画，都应该建立在少量稳定的“标准参考图”之上。
