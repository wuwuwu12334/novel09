# 一、核心目标

Novel09 的视觉不能做成普通“仙侠手游宣传图”。

需要同时保留三种气质：

1. **少年篇的明亮、清洁与相信世界**；
2. **旧案篇的制度压迫、宗门秩序感与逐渐收紧的窒息感**；
3. **四百余年后的陌生、破碎、域外侵蚀感**。

沈照夜是整个视觉体系最重要的时间轴：

- 少年时期：干净、漂亮、锋利，冷白月色。
- 被囚时期：颜色逐步褪去，身体和空间都开始“失去完整性”。
- 域外归来：不做传统魔尊红黑火焰，而是灰黑、失色、空间裂痕、反常静默、黑晶与异常光。

---

# 二、角色一致性原则

后续所有 AI 出图必须优先保持：

- 脸型与五官比例；
- 发型主体结构；
- 角色主色；
- 标志性饰物；
- 武器或力量视觉语言；
- 身形与年龄感；
- 不同时间线之间仍能一眼认出是同一个人。

允许变化：

- 表情；
- 姿势；
- 镜头；
- 战损；
- 场景；
- 同一体系内的礼服 / 常服 / 战斗服变化。

---

# 三、推荐出图顺序

为了保证后面批量生成不跑脸，建议先完成：

1. 沈照夜少年标准立绘；
2. 沈照夜四百年后标准立绘；
3. 宁知微少年标准立绘；
4. 宁知微四百年后标准立绘；
5. 楚清妤少年标准立绘；
6. 楚清妤四百年后标准立绘；
7. 陆沉舟标准立绘；
8. 天衍圣宗鸟瞰地图；
9. 照月峰局部地图；
10. 后山禁地局部地图。

这些图确定后，再用它们作为后续场景图的角色/环境参考。

# 四、默认画面规格

## 人物设定图

- 2:3 或 3:4 竖构图；
- 全身优先；
- 同时保留半身特写版本；
- 背景尽量简洁，不抢人物；
- 需要清晰展示服装层次、发饰、武器、纹样。

## 剧情插画

- 16:9 横构图为主；
- 强调环境与人物关系；
- 少用人物正面站成一排；
- 用前景遮挡、远近层次、建筑尺度制造电影感。

## 地图

- 16:9 或 4:3；
- 优先“古典山水地形图 + 清晰空间结构”，而不是纯游戏 UI；
- 第一版建议不直接让 AI 生成大量中文文字，先出无字地图，再人工或后续模型加标注。

# 五、画风关键词总览

**东方玄幻、电影级概念设计、写实二次元融合、古典修真建筑、克制华丽、真实材质、体积光、云海、山体尺度、复杂但不杂乱、人物脸部精致自然、非手游塑料感。**

重要原则：

> 漂亮不等于堆金色；强大不等于全身发光；邪异不等于红眼黑甲。

Novel09 最有辨识度的东西，是“同一个世界从月色秩序走向空间破碎”。
