# novel09

一部长篇玄幻双主角小说。

## 核心故事

数百年前，天衍圣宗绝世天骄 **沈照夜** 被诬陷杀害谢临川。

他的青梅竹马 **楚清妤** 同时与谢临川存在男女感情，并长期维持模糊边界。命案发生后，她在感情偏向与自身利益驱动下迅速认定沈照夜有罪，并借楚氏力量推动定罪；只有师妹 **宁知微** 始终相信沈照夜没有杀人。

宗门最终没有处死沈照夜，却废掉修为、毁去经脉、打断双腿，并在主峰中央公开示众七日后，将他永久囚禁后山。

九年后，他从后山消失，进入域外。

四百余年后，从边域成长起来的 **陆沉舟** 进入天衍圣宗。一系列灭村、灭门和域外力量事件，使一桩早已被尘封的旧案重新浮出水面。

而当年那个无辜的少年，也已经从域外归来。

这一次，他真的成为了天下眼中的敌人。

最终故事不会以传统“正道主角击败终极反派”结束：陆沉舟会在最终大战中战死，沈照夜成为最后的胜利者。

## 当前文风硬规则

- 对白首先表现人物当下的情绪、关系和目的，其次才负责传递信息。
- 重要对话必须有阻力，不写连续“问一句—答一句”的表格式交流。
- 不连续堆裸对白；用动作、视线、物件、声音变化重新锚定人物。
- 少用“某某说/某某问”机械报幕，不使用大量库存表情。
- 楚清妤的“会装”必须通过她自己的话和行为表现，不由旁白直接替读者下结论。
- 战斗不得站桩轮流报招，必须写清距离、地形、连续反应、判断和代价。
- 重要战斗必须同时满足“底层有战术逻辑 + 上层有华丽视觉奇观”。不能只靠主角看破弱点来制造爽点。
- 关键招式允许有正式名称，并拥有固定的视觉语言。沈照夜少年时期以冷白月辉、月轮、剑影和月色剑河为核心；不同传承必须有不同颜色、形态和压迫感。
- 重要战斗至少包含两个明确形态的招式特效、一次覆盖大面积视野的力量爆发、一次强招正面碰撞和一次明显环境破坏。
- 大特效必须留下后果：山壁剑痕、擂台沟壑、树木断裂、岩石熔化、阵壁震动等，不能放完特效就恢复原状。
- 沈照夜少年时期既要体现观察和临场判断，也必须让读者真正感到他的剑本身足够强、足够漂亮。
- **后续正文默认单章约2000字，常规范围1800—2200字。重要大战、重逢、真相等内容可以略超，但优先拆成连续章节，不再默认写成五六千字长章。**
- **一章仍需有完整内部弧线，但不为了“写厚”强行延长；把最适合这一章的事件写完整即可。**
- **长篇不能一直只有修炼、任务、调查和战斗。大阶段之间要主动安排生活章，让人物逛庙会、年会、灯市、吃饭、休沐、下山、聊天，允许一整章没有命案和主线推进。**
- **轻松章不是全员贫嘴。每个人仍需保持自己的说话习惯、生活偏好和关系差异。**

## 当前核心剧情硬规则

- 楚清妤同时喜欢沈照夜与谢临川，并主动维持两边的模糊关系。
- 旧案证据有指向性但并不完美。
- **宁知微是旧案发生后唯一从头到尾明确说“我信沈照夜没杀人”的人。**
- 秦长老、宗主、周行等人可以觉得案件有疑点、觉得沈照夜不像凶手、想继续调查，但不能成为第二个明确相信他无罪的人。
- 被诬陷到最终定罪必须写成长篇坠落：先失去信任，再失去身份、未来和关系，最后才失去修为、经脉和双腿。
- 公开审判必须持续多日，不只审谢临川命案；罪名会扩张到域外勾连、禁物接触、窥探宗门机密、旧任务异常、失踪案等多个方向。
- 楚清妤必须在公开审判中从“体面受害者”逐步暴露为主动利用证词、舆论和楚氏力量推动定罪的人；发现疑点后也不能轻易回头。
- 楚氏施压必须体现为资源、商路、会盟、盟友和宗门声誉等现实代价，使宗门高层逐步从“继续查”退到“先稳定局势”。
- 沈照夜最终不是因为所有罪名都被证明才被废，而是因为越来越多人认为“即便还有疑点，留着他也太危险”。
- **第72章刑罚结束后，沈照夜不得立刻进入后山；必须先在主峰中央问罪坪示众七日，以横展双臂的问罪架固定，完成公开羞辱与社会性处刑。**
- 七日示众中允许围观、辱骂、吐口水、扔泥和烂果，但宗门会阻止真正致死攻击；楚清妤必须到场，宁知微必须持续保护和探视。
- 楚清妤在示众期不能突然变成粗暴泼妇；她越是表现得体面、难受、甚至劝别人“别骂了”，越要同时暴露她仍不肯承认自己推动这一切有错。
- **第二卷前期必须让陆沉舟独立成立，不围绕沈照夜旧案开局；不让他直接得到沈照夜传承，也不让沈照夜暗中选中他。**
- **陆沉舟综合天赋必须真正处于顶尖层级。第109章风、金中下亲和只代表基础测灵结果；真正核心是“断流灵觉”带来的顶级悟性、力量结构感知与实战学习速度。**
- **陆沉舟前期真心相信名门正派、执法殿与宗门秩序；顾玄策必须先成为他真心敬重的正道前辈，楚清妤前期也应被他视为值得尊敬的旧案受害者。**
- **陆沉舟初知沈照夜旧案时先相信官方定论，并会因顾玄策、楚清妤和楚氏的赏识逐渐主动维护他们。沈照夜正式回归前，他只能维护官方旧案、反对翻案、替顾玄策和楚清妤辩护；只有沈照夜回归、陆沉舟确认身份并形成直接阵营冲突后，才允许出现当面用旧案和“罪徒”身份刺激沈照夜的剧情。**
- **楚氏必须长期、现实地扶持陆沉舟：资源、名师、试炼、身份、权力逐步增加；最终他事实上成为楚氏最重要的年轻力量和最锋利的一把刀，形成强烈功能性依附。**
- **宁知微不会天然喜欢陆沉舟。她会因为陆沉舟未经真正调查就相信官方旧案、替顾玄策与楚清妤辩护、主动维护错误历史定性而越来越厌恶他；沈照夜回归后的直接冲突只会进一步恶化两人关系。**
- **旧案真相开始浮现后，陆沉舟不能立刻洗白；必须先抵抗、质疑证据、替自己信任的人找理由，再逐步被事实击穿。**
- **沈照夜与宁知微重逢时，宁知微应明显激动并主动拥抱；沈照夜会像四百多年前一样自然接住并抱回去。两人可以立场冲突，但关系不能写成陌生人式疏离。**
- **楚清妤确认沈照夜归来后的前期不敢与真人面对，只敢通过传影镜、阵幕、远距离传讯等方式隔空相见；真正面对面必须更晚，并成为一次明确的剧情跨越。**
- 沈照夜无论后期黑化到什么程度，都绝不会杀宁知微。
- 沈照夜后期确实会造成无辜者死亡，不能全部洗白。
- 陆沉舟最终确认沈照夜当年无罪，但仍会为了阻止今天的灾难与他决战。
- 最终陆沉舟战死。
- 沈照夜获胜。
