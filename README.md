# novel09

一部长篇玄幻双主角小说设定仓库。

## 核心故事

数百年前，一名原本前途无量的绝世天骄被诬陷杀害同道。

青梅竹马因同时对死者存在感情，在悲痛与偏见中迅速认定他是凶手；只有师妹始终相信他无罪。

宗门最终没有处死他，却废掉修为、毁去经脉、打断双腿，将他永久囚禁后山。

九年后，他从后山消失，进入域外。

四百余年后，另一个从边域成长起来的少年进入当年的宗门。一系列灭村、灭门和域外力量事件，使一桩早已被尘封的旧案重新浮出水面。

而昔日那个无辜的少年，也已经从域外归来。

这一次，他真的成为了天下眼中的敌人。

最终故事不会以传统“正道主角击败终极反派”结束。

正牌男主会在最终大战中战死，昔日天骄成为最后的胜利者。

## 当前核心硬规则

- 青梅竹马同时喜欢昔日天骄与谢临川，并非纯粹“男闺蜜”关系。
- 旧案证据有指向性但并不完美。
- 师妹从始至终相信昔日天骄无罪。
- 昔日天骄无论后期黑化到什么程度，都绝不会杀师妹。
- 昔日天骄后期确实会造成无辜者死亡，不能全部洗白。
- 正牌男主最终确认昔日天骄当年无罪，但仍会为了阻止今天的灾难与他决战。
- 最终正牌男主战死。
- 昔日天骄获胜。
